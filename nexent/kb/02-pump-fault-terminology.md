# 离心泵故障术语说明

本文件是知识库中的**术语说明**，用于解释现场口语与本体术语的对应关系。它不含任何具体设备的运行记录，不能作为某台设备故障结论的证据。设备事实以 MCP 工具返回的逐字原文为准。

## 出口压力不足

泵出口压力低于该泵正常工作范围，现场常称「压力不够」「压力低」「扬程不足」。本体中的故障事件名为「出口压力不足」，`fault_name` 字段使用该名称，别名包含「出口压力低」「压力不够」。

它是**现象或顶层故障事件**，通常不是根因。诊断时应沿故障树向下查找导致该现象的原因分支。

## 入口过滤器堵塞

泵入口过滤器流通面积减小，导致入口流量下降、泵入口压力降低，进而表现为出口压力不足。现场常直接称「过滤器堵了」。

本体中的故障事件名为「入口过滤器堵塞」，属于原因类故障，常作为顶层事件的子节点。

## 叶轮汽蚀

泵入口局部压力低于介质饱和蒸气压时，液体汽化形成气泡，气泡在叶轮处溃灭并冲击叶片，长期作用会损坏叶轮。表现为噪声、振动、出口压力波动或下降。

本体中的故障事件名为「叶轮汽蚀」，属于原因类故障。汽蚀的判定通常需要入口压力、介质温度和振动/噪声信息共同支持，单一压力读数不足以确认。

## 吸入管法兰漏气

吸入管路法兰密封失效，空气进入吸入侧，导致泵吸入能力下降、出口压力不足，常伴随流量不稳。

本体中的故障事件名为「吸入管法兰漏气」，属于原因类故障。

## 逻辑门与规则

- 「出口压力不足」在故障树中通常由多条原因通过 **OR** 门连接：任一原因成立即可解释该现象。
- 部分原因（如汽蚀）由多个条件通过 **AND** 门连接：所有条件同时成立才判定该原因。
- 规则表达式与逻辑门以 MCP 工具返回的故障树数据为准，本文件不重复列举，避免与本体版本不一致。

## 使用建议

- 用户使用口语（如「泵抽不上水」）时，先映射到上面的本体术语，再用 `search_faults` 检索。
- 术语映射只用于检索，不作为结论；结论仍须由 `trace_evidence` 的原文支撑。
- 本体版本升级后，以 `get_ontology` 返回的类与关系定义为准。
